# Ejecución local

## 1. Instalar dependencias

Este comando instalará todas las librerías necesarias del proyecto.

```bash
npm install
```

---

## 2. Ejecutar el servidor de desarrollo

```bash
npm run dev
```

---

## 3. Abrir el proyecto en el navegador

Una vez iniciado el servidor, abre la siguiente dirección en tu navegador:

```txt
http://localhost:5173
```
